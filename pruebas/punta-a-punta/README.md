# Punta a punta (Playwright)

- `camino-critico.spec.ts` — crear evento → crear sala → transcribir un audio de `muestras/` → la audiencia recibe los subtítulos.
- `desatendida.spec.ts` — la sala arranca por agenda, se simula una falla y se repara sola.
- `audiencia.spec.ts` — varios espectadores eligen idiomas distintos y reciben la misma línea.
