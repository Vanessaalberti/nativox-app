# subtitulos ♻

- `LineaSubtitulo` — una línea: original (opcional, chico) + traducción; estado provisorio (gris / "…").
- `VistaSubtitulos` — las últimas N líneas, la nueva abajo y las anteriores atenuadas; tamaños y fondo configurables (pantalla del escenario, overlay transparente, celular).

Reciben líneas ya armadas (`compartido/contratos`) y el idioma a mostrar; no se conectan a nada.
