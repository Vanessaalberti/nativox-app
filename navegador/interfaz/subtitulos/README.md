# subtitulos ♻

- `LineaSubtitulo` — una línea: original (opcional, chico) + traducción grande; mientras es provisoria, el original va en gris y la traducción como "…". Tamaños S/M/L en píxeles a 1920 de ancho.
- `VistaSubtitulos` — las últimas N líneas con texto, la nueva abajo y las anteriores atenuadas; con un texto para cuando todavía no hay nada.

Reciben líneas ya armadas (`compartido/contratos`) y el idioma a mostrar; no se conectan a nada. Los usan la pantalla del escenario y, desde el paso 5, la audiencia y vMix/OBS.
