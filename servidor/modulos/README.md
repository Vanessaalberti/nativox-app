# modulos ♻ — piezas reutilizables del servidor

| Módulo | Qué resuelve |
| --- | --- |
| `avisos` | Avisos a Discord, Slack y Google Chat |
| `links-de-accion` | Links de acción de un solo uso con vencimiento |
| `cripto-acceso` | Contraseñas, sesiones y códigos con WebCrypto |
| `medidor-consumo` | Consumo estimado de IA y topes |
| `audio-wav` | Revisa y mide el audio WAV que llega para transcribir en la nube |

Mismas reglas que `navegador/modulos/`: no importan nada de fuera de su carpeta, salvo `compartido/`.
